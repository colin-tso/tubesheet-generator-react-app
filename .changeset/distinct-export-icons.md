Give each export action its own icon instead of a shared floppy disk with a tiny label: a vector curve for SVG, a picture frame for PNG, a page for PDF, a set square for DXF, an "XY" box for coordinates (CSV), and braces with a down or up arrow for Save and Load JSON. All icons share one 16px grid and 12px square live area so they look the same size.
