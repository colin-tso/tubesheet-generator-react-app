| Term | Notation | Meaning |
| --- | --- | --- |
| Angle between radial tubes | $\theta_\text{radial}$ | Angle subtended by neighbouring tubes on a radial ring. |
| Column index | $i$ | Which column a tube belongs to, counting outward from the centre. |
| Field offset | $S$ | Whole-field shift (0 or $\dfrac{dx}{2}$) chosen automatically to maximise tube count. |
| Layout angle | $\theta$ | Named angle (30°/45°/60°/90°) between the pitch line and the row direction: $\arctan(C / dy).$ |
| OTL | $\text{OTL}$ | Outer Tube Limit: diameter of the smallest circle enclosing every tube, wall-to-wall. |
| <span class="docs-glossary-subterm">Actual OTL</span> | $\text{OTL}_\text{act}$ | The actual OTL measured from the generated tube field. |
| <span class="docs-glossary-subterm">Maximum allowable OTL</span> | $\text{OTL}_\text{max}$ | The maximum OTL the pattern is allowed to reach, set by the shell ID and OTL clearance. |
| <span class="docs-glossary-subterm">OTL clearance</span> | $\text{OTL}_\text{clear}$ | The diametrical gap between the outermost tube walls and the shell ID. |
| Packing factor | $k$ | Empirical density constant (0.84 triangular, 0.61 square) used to seed the shell ID search algorithm. |
| Pitch | $P_t$ | Centre-to-centre distance between neighbouring tubes. |
| <span class="docs-glossary-subterm">Pitch (tube) clearance</span> | $P_\text{clear}$ | Wall-to-wall gap between neighbouring tubes: $P-D_\text{tube}$. |
| <span class="docs-glossary-subterm">Pitch ratio</span> | $P_\text{ratio}$ | Pitch expressed as a multiple of the tube OD. |
| Ring diameter | $D_\text{ring}$ | Diameter of a single concentric ring in a radial layout. |
| Row | | One horizontal line of tubes in the pattern. |
| <span class="docs-glossary-subterm">Row index</span> | $j$ | Which row a tube belongs to, counting outward from the centre. |
| <span class="docs-glossary-subterm">Row spacing</span> | $d_x$ | Spacing between neighbouring tubes within a row. |
| <span class="docs-glossary-subterm">Row stagger</span> | $C$ | Horizontal stagger applied to alternating rows. |
| <span class="docs-glossary-subterm">Row-to-row spacing</span> | $d_y$ | Vertical spacing between rows. |
| Shell ID | $D_\text{shell}$ | Inside diameter of the shell the tubesheet sits in. |
| <span class="docs-glossary-subterm">Initial diameter estimate</span> | $D_\text{shell, est}$ | Closed-form starting guess for the inverse (minimum-tube-count) solve. |
| <span class="docs-glossary-subterm">Minimum shell ID</span> | $D_\text{shell, min}$ | Smallest shell ID that can hold a requested minimum tube count. |
| Tube count | $n$ | Number of tubes in the generated pattern. |
| <span class="docs-glossary-subterm">Actual tube count</span> | $n_\text{act}$ | Number of tubes the generator actually produced for a given shell. |
| <span class="docs-glossary-subterm">Minimum tube count</span> | $n_\text{min}$ | Target minimum number of tubes, used to solve for the smallest shell ID. |
| Tube OD | $D_\text{tube}$ | Outer diameter of one tube. |
| Tube position | $x,\ y$ | The horizontal and vertical positions of a tube relative to the middle of the tube sheet. |
