### Solve for number of tubes, given a 500 mm shell

With $\text{OTL}_\text{max} = 500 - 12.7 = 487.3\ \text{mm}$ (<EqRef id="otl-max" />), the generator produces:

:::Formula{id="example-forward-result" label="Result"}
$$

n_\text{act} = 349, \quad \text{OTL}_\text{act} = 478.33\ \text{mm}
\end{align}
$$

The actual OTL, 478.33 mm, comes in under the 487.3 mm ceiling: the discrete triangular pattern cannot use every last fraction of a millimetre available.

### Solve for minimum shell ID, given a target of 350 tubes

Solving for the smallest shell ID ($D_\text{shell, min}$, <EqRef id="solving-initial-estimate" />) that holds at least 350 tubes gives:

:::Formula{id="example-inverse-result" label="Result"}
$$
\begin{align}
D_\text{shell, min} = 500.20\ \text{mm}, \quad n_\text{act} = 352
\end{align}
$$
:::

The result overshoots the 350-tube target slightly, landing on 352, since the next diameter down would have dropped below 350. So 500.20 mm is the tightest shell ID that still clears the target.
