# Documentation

This documentation explains the geometry and numerical methods behind the
calculator:

- What [pitch and pitch ratio](#/docs/pitch), [OTL](#/docs/otl), and the [layout angles](#/docs/patterns) actually mean
- How a [full tube field is generated](#/docs/filling) from a handful of constants
- How the calculator solves the [inverse problem of finding the smallest shell](#/docs/solving) that fits a target number of tubes.

All formulae in this document match the layout generator used by the calculator.
