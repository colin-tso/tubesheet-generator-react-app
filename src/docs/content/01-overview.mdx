A tubesheet layout is a repeating pattern of tube centres, packed as densely as the geometry allows inside a circular boundary. The calculator requires five inputs to fully determine that pattern:

1. **Tube OD** ($D_\text{tube}$): the outer diameter of a single tube.
2. Either
    1. **Tube clearance** ($P_\text{clear}$): the wall-to-wall gap between adjacent tubes, or
    2. **Pitch ratio** ($P_\text{ratio}$): the pitch, expressed as a multiple of the tube OD.
3. **Layout**: the angle of the repeating pattern (30°, 45°, 60°, 90°, or a concentric-ring radial layout).
4. **OTL clearance** ($\text{OTL}_\text{clear}$): the diametrical allowance between the outermost tube walls and the shell inside diameter (ID) — half of it on each side.
5. Either 
    1. **Shell ID** ($D_\text{shell}$): to solve for the tube count it can hold, or
    2. **Minimum tube count** ($n_\text{min}$): to solve for the smallest shell ID that can hold that many tubes.

Everything else, including the pitch, the tube field, the OTL, and the shell ID when it is not a direct input, is derived from those five values.
